# OpenManus: An Autonomous AI Agent Framework

**OpenManus** is an open‐source framework for building autonomous AI agents. It lets you create agents that take in natural language instructions and use various tools to plan and execute tasks.

## Inputs & Outputs

- **Inputs:**
  - Text commands entered via a command-line interface or API requests.
  - Configuration files (e.g., `config.toml`) that define LLM settings and API keys.
- **Outputs:**
  - Textual responses and reports generated by the agent.
  - Structured results such as dashboards, file outputs, or API responses when tools are used.

## Reasoning Capabilities

- OpenManus uses a multi-step planning approach based on the **ReAct paradigm**:
  - **Think:** Agents first "think" by planning the next steps.
  - **Act:** Then, they "act" by invoking the appropriate tools.
- Agents like the **Manus** or **PlanningAgent** integrate LLM responses with tool calls (e.g., executing shell commands, searching the web, or performing file manipulations) to iteratively refine their output.

## Key Code Areas to Explore

- **Agents:**  
  Look into the `app/agent` folder for various agent implementations:
  - `manus.py`
  - `react.py`
  - `planning.py`

- **Tools:**  
  Check out the `app/tool` directory to see how different tools are implemented, such as:
  - Bash executor
  - Google Search integration
  - File saver

- **Flows:**  
  The `app/flow` directory (especially `planning.py`) demonstrates how the agent’s reasoning and task execution are managed.

## Overview

This modular design lets you follow the entire data flow—from receiving input, planning via the agent’s reasoning loop, to executing tool calls and delivering output. It is designed to be flexible and extendable, enabling developers to customize and add new functionalities to meet their specific requirements.
